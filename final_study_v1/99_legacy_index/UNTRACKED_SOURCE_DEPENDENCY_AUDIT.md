## Method and limits

The audit starts from the 115 staged Python files and follows Python `import`/`from` statements recursively, preferring same-directory modules and otherwise resolving unique module names. It separately checks promoted `source_sha256.json`/`protected_sha256_before.json`, generated V2.2 source references, Edge source-copy/frozen-bundle logic, and forward Grid03 helpers. It checks direct file/path and subprocess references in the shared runtime. A source path listed as required is **proposed TRACK**, including old-looking transitive modules; directory age alone does not determine classification. The five former REVIEW_REQUIRED paths are now resolved as TRACK_REQUIRED_DEPENDENCY through frozen source-hash guards. The dependency closure is static; conditional imports and future Grid03 design can add dependencies, so forward-only candidates are identified separately.

Key chains: promoted Local calibration/K-sweep → `common/v2_2/{v22_config,v22_builder,run_validation}` → `service_phase_b1`, `service_phase_v1`, `block_b_split/v2_1`, `v2`; promoted Edge/Grid/Confirmation → `common/{campaign_config,campaign_analysis,reuse,dispatch_observation,edge_preflight}` → D100/pruning/canonical/equal-service predecessor modules. Frozen Edge bundles retain protocol/server sources copied from `scripts/edge_raw_capacity_gate/` and `scripts/expired_work_pruning/`. Promoted source-hash manifests explicitly name additional validation sources. The runbook and historical Edge source are therefore reproducibility assets despite their untracked state.
