# Future physical-cleanup checklist — no cleanup authorized here

Physical deletion is a separate future decision. A scientific campaign directory is eligible for consideration only if **all** conditions are documented as true:

1. It is not referenced by the final paper.
2. It is not in either Configuration A or Configuration B evidence chain.
3. It is not needed for runtime-configuration justification.
4. It is not failed-history or provenance that must remain preserved.
5. Required small evidence has been indexed or promoted by canonical path and verified SHA-256.
6. The plan, preregistration when present, analyzer, and provenance chain is preserved.
7. A Git and downstream dependency audit passes.
8. `FINAL_STUDY_MANIFEST.json` explicitly marks it eligible for cleanup.
9. The user separately approves the specific physical deletion.

No directory currently meets an approved deletion gate in this index. All twelve promoted v2_2 campaigns, including motivating/foundational measurements, E72/E80 preflight, Configuration A, Local calibration03–05, Robustness02, and the K-sweep, are protected. Every `FAILED_OR_INVALID_RETAIN` campaign is protected. `UNDECIDED_RETAIN` and preliminary campaigns remain local pending explicit later review. Git untracking, if approved later, is separate from physical deletion.
