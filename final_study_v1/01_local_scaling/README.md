# Final-configuration Local scaling

[LOCAL_FINALCONFIG_KSWEEP01](LOCAL_FINALCONFIG_KSWEEP01/README.md) is a formal baseline at C_L=3, B=1, Edge OFF, deadline 100 ms. It changes actual stream count K=1..8 at 30 FPS per physical stream; five repeats per K were all VALID (40/40). It does not select C_L and it does not add a post-hoc sustainable-K threshold.
