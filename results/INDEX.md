# Research artifact index

This is a classification layer; all original artifact directories and frozen
code remain at their existing physical paths. No measurements were moved,
rewritten, regenerated, or deleted by the layout cleanup.

- [Active](active/README.md): current static-concurrency range discovery.
- [Reference](reference/README.md): canonical Local C2 reference.
- [Archive](archive/README.md): earlier characterization and preserved exploration.

Only relative symlinks whose targets already have tracked files are committed.
Local-only campaigns are listed as plain paths in the indexes, not as links to
targets missing from GitHub. Tracked targets may still require ignored raw files
for full reproduction; these files are not published by the navigation links.

Other existing result directories remain unclassified at their original paths.
See [layout policy](../docs/results_layout.md) for dependency and preservation notes.
